# Каталог плагинов Codex

Полный каталог магазина плагинов приложения **ChatGPT (Beta) / Codex** на русском языке.

**Открыть:** https://projectspeedup-commits.github.io/plagin-gpt/

## Что внутри

3159 плагинов, все 15 категорий магазина. У каждой позиции без исключения:

- название и категория, как в магазине;
- описание на русском — что делает и для чего нужен;
- тип тарифа: бесплатно, есть бесплатный уровень, только платно, входит в подписку;
- три примера, что можно сделать с помощью этого плагина;
- пошаговая инструкция простыми словами — куда нажимать в приложении;
- готовый промт, который копируется одной кнопкой;
- список файлов, которые нужно приложить к запросу;
- условия использования и подробности тарифа.

## Как пользоваться страницей

- **Поиск по задаче.** Наберите задачу словами — «красивая диаграмма», «найти билеты», «смонтировать видео» — или нажмите готовый чип задачи. Все подходящие категории раскроются целиком.
- **Фильтры.** По условиям оплаты, приоритету, категории, а также «для бизнеса», «для продаж», «установлены у вас», «тариф сверен в сети», «есть код на GitHub».
- **Раскрытие карточки.** Нажмите на строку таблицы — откроется полное описание с инструкцией и промтом.
- Шапка категории и шапка колонок закреплены при прокрутке; панель фильтров сворачивается кнопкой.

## Как собраны данные

Каталог нигде не отдаётся через API и не кэшируется на диске — он снят с экрана приложения категория за категорией и переведён вручную.

Тарифы 25 крупнейших сервисов сверены поиском в интернете в августе 2026 — у них указаны настоящие суммы, и они помечены фильтром «Тариф сверен в сети». У остальных указан только тип тарифа, а сумма честно помечена «уточняется»: её нужно смотреть на сайте сервиса.

Собственных цен в магазине Codex нет ни у одного плагина: в карточке только разработчик, версия, права доступа и ссылки. Установка всегда бесплатна — платите вы за подписку ChatGPT и за сам внешний сервис по тарифу его владельца.

Рейтингов и оценок магазин не показывает вообще — ни звёзд, ни числа установок, ни отзывов. Единственный доступный сигнал популярности — звёзды GitHub у тех плагинов, за которыми стоит публичный репозиторий; таких 24 из 3159.

## Устройство репозитория

```
site/index.html              — вся страница одним самодостаточным файлом
.github/workflows/pages.yml  — публикация на GitHub Pages при пуше в main
```

Внешних зависимостей нет, кроме шрифтов Google Fonts. Данные, разметка, стили и логика лежат в одном файле.
